# Bundled Iwona Type 1 subset

This directory contains Iwona regular, italic, bold, and bold-italic Type 1
fonts, their T1 metrics, and encoding files. `setup.tex` uses these files only
for `style=arsclassica` under pdfLaTeX.

Source: Iwona 0.995b, https://ctan.org/pkg/iwona
